# Contributing to Smart Assignment Recommender (RAG System)

Thank you for your interest in contributing! This project is an enterprise-grade Retrieval-Augmented Generation (RAG) platform tailored for educational institutions and personalized learning paths.

## Development Workflow

1. **Fork & Clone**:
   ```bash
   git clone https://github.com/AdityaPandey-DEV/smart-assignment-recommender.git
   cd smart-assignment-recommender
   ```

2. **Environment Setup**:
   ```bash
   make install
   ```

3. **Running Tests**:
   ```bash
   make test
   ```

4. **Code Quality Standards**:
   - Python code must conform to PEP 8 standards and Pydantic v2 typing.
   - Vector operations must maintain L2 normalization invariants.
   - React components must adhere to the modular vanilla CSS token system.

5. **Submitting Changes**:
   - Open a detailed Pull Request explaining the rationale, test coverage, and benchmark impact.
